CSSプロパティ一覧

よく使うものだけを厳選した。CSSは数百種類あるが、実際に使うのはこの程度。

セレクタ色文字 余白・大きさ枠線・影Flexbox Gridposition動き その他単位

セレクタ（どこを指定するか）

書き方意味
pすべての <p> タグ
.boxclass="box" が付いた要素（いちばんよく使う）
#headid="head" の要素
.box pbox の中にある p（スペース＝子孫）
.box > pbox の直接の子の p
h1, h2h1 と h2（カンマ＝両方）
.card.bigclass に card も big も付いている要素
a:hoverマウスが乗っているとき
button:active押している瞬間
input:focus入力中（カーソルが入っている）
li:first-child最初の子要素
li:last-child最後の子要素
li:nth-child(2)2番目の子要素
tr:nth-child(even)偶数番目（表の縞模様に）
.box::before中身の前に飾りを足す（content が必要）
*すべての要素
:rootページ全体。CSS変数を書く場所
優先順位（同じ場所に複数当たったとき） タグ名 < class < id < style属性。より細かく指定したほうが勝ち。 どうしても勝たせたいときは !important を付けるが、最終手段。

色

プロパティ値の例説明
color#33333d / crimson文字の色
background-color#f4f1e8背景の色
background#fff url(bg.png)背景まとめて指定
background-imageurl("bg.jpg")背景画像
background-sizecover / contain背景画像の伸ばし方
opacity0.5透明度。0で見えない、1で不透明
（色の書き方）rgba(0,0,0,0.5)赤・緑・青・透明度。半透明にしたいとき
（グラデーション）linear-gradient(90deg, #a, #b)色の帯。background に指定する

文字

プロパティ値の例説明

font-weightbold / 600太さ

text-decorationnone下線。リンクの下線を消すのに使う
text-decorationline-through取り消し線
font-styleitalic斜体
white-spacenowrap折り返さない
text-shadow0 1px 2px #0003文字に影

余白・大きさ

プロパティ値の例説明
margin20px / 12px 24px外の余白（箱どうしを離す）
margin: 0 auto—中央寄せの定番。width が必要
padding20px 24px内の余白（箱の中を広げる）
width / height200px / 100%幅・高さ
max-width940pxこれ以上広げない。レスポンシブの要
min-height100vh最低でもこの高さ
box-sizingborder-boxpadding や border を幅に含める。最初に書いておく
overflowhidden / autoはみ出した中身を隠す／スクロールさせる
displayblock / inline-block / none要素の性格を変える。none で消える
余白の書き方（時計回り） padding: 20px＝4辺／padding: 12px 24px＝上下・左右／ padding: 12px 24px 30px＝上・左右・下／ padding: 12px 24px 30px 8px＝上・右・下・左

枠線・角丸・影

プロパティ値の例説明
border1px solid #ddd枠線。太さ 種類 色 の順
border-left6px solid crimson左だけ。これ1本で見た目が締まる
border-radius8px / 50%角丸。50%で円になる
box-shadow0 2px 8px rgba(0,0,0,.15)影。横 縦 ぼかし 色
（border の種類）solid dashed dotted none実線・破線・点線・なし

Flexbox（一列に並べる）

プロパティ値の例説明
display: flex—親に書く。子が横に並ぶ
flex-directionrow / column横並び／縦並び
gap18px子どうしの間隔
justify-contentcenter / space-between横方向の配置
align-itemscenter / stretch縦方向の配置
flex-wrapwrap入りきらないとき折り返す
flex（子に書く）1余った幅をもらって伸びる
flex（子に書く）none縮まない。画像やボタンに

Grid（格子に並べる）

プロパティ値の例説明
display: grid—親に書く
grid-template-columnsrepeat(3, 1fr)3等分の列を作る
grid-template-columns200px 1fr左は固定、右は残り全部
gap12pxマスの間隔
place-items: center—タテヨコ完全に中央。覚えておくと便利
grid-row / grid-column2子を置く場所を直接指定

position（重ねる・固定する）

値説明
staticふつう（初期値）
relative元の位置を基準にずらす。absolute の基準にもなる
absolute流れから外れ、親（relative）を基準に配置
fixed画面に貼りつく（スクロールしても動かない）
stickyスクロールして端まで来たらそこで止まる。top: 0 とセット
top right bottom left位置。inset: 0 で四辺まとめて
z-index重なり順。数字が大きいほど手前。position が必要

動き

プロパティ値の例説明
transitionall 0.2s変化にかける時間。元の状態に書く
transformtranslateY(-5px)動かす
transformscale(1.05)拡大・縮小
transformrotate(3deg)回転
@keyframes 名前—アニメーションを定義する
animationbob 1.4s infinite定義したアニメを適用
cursorpointerマウスカーソルを指の形に

その他・レスポンシブ

--名前: 値;CSS変数を作る（:root に書く）

content: "★";::before / ::after で足す中身

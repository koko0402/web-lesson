HTMLタグ一覧

この講座で出てくるタグを全部まとめた。おぼえる必要はない。忘れたらここを見るためのページ。

土台文章リスト リンクと画像まとまり表 フォーム属性特殊文字

土台（毎回書くもの）

タグ読み・由来説明
<!DOCTYPE html>ドクタイプ「これはHTML」という宣言。ファイルの1行目に必ず書く
<html lang="ja">エイチティーエムエル全体のいれもの。lang="ja" で日本語のページだと伝える
<head>ヘッド画面に出ない設定を書く場所
<meta charset="UTF-8">メタ・キャラセット文字コードの指定。これが無いと文字化けする
<meta name="viewport"…>ビューポートスマホで正しい大きさで表示するためのおまじない
<title>タイトルブラウザのタブに出る名前。検索結果の見出しにもなる
<link rel="stylesheet">リンクCSSファイルを読み込む。head の中に書く
<script src="…">スクリプトJavaScriptを読み込む。body の一番下に書く
<body>ボディ画面に出る中身を書く場所

文章

タグ読み・由来説明
<h1> 〜 <h6>heading（見出し）見出し。数字が小さいほど大きい。h1 は1ページに1つ
<p>paragraph（段落）文章のひとかたまり
<br>break（改行）その場所で改行。終了タグなし
<hr>horizontal rule話題の区切りの横線。終了タグなし
<strong>ストロング重要という意味。初期状態では太字
<em>emphasis（強調）強調。初期状態では斜体
<b>boldただ太くするだけ（意味なし）
<small>スモール注釈・補足。小さい字になる
<mark>マーク蛍光ペンで引いたような黄色背景
<s>strike取り消し線
<blockquote>ブロッククォート引用のかたまり
<code>コードプログラムのコードを示す（等幅フォントになる）
<pre>preformatted改行やスペースをそのまま表示する
<!-- コメント -->—画面に出ないメモ。Ctrl + / で切り替え

リスト

タグ読み・由来説明
<ul>unordered list順番なしのリスト（黒丸）
<ol>ordered list順番ありのリスト（番号は自動）
<li>list itemリストの1項目。ul か ol の中に入れる
<dl>description list「用語と説明」のリスト
<dt>description term用語のほう
<dd>description details説明のほう

リンクと画像

タグ読み・由来説明
<a href="…">anchor（いかり）リンク。href に飛び先を書く
<a href="#id">—同じページの中の、その id の場所へ飛ぶ
<a target="_blank">—新しいタブで開く
<img src="…" alt="…">image画像。終了タグなし。alt は必ず書く
<video> <audio>—動画・音声。controls を付けると再生ボタンが出る
<iframe>アイフレーム他のページ（YouTube や地図）を埋め込む
パス（道順）の書き方 photo.png＝同じフォルダ／img/photo.png＝img の中へ降りる／ ../photo.png＝1つ上のフォルダへ上がる／https://…＝ネット上

まとまり・場所

タグ読み説明
<header>ヘッダーページの上部（題名・ロゴ）
<nav>ナビ他のページへのリンク集
<main>メインそのページの主役。1ページに1つ
<section>セクション意味のまとまり。見出しとセットで使う
<article>アーティクルそれ単体で成立する記事
<aside>アサイドおまけ・補足・サイドバー
<footer>フッターページの下部（著作表示など）
<div>division意味のない箱（ブロック）。CSSを当てる目印に
<span>スパン意味のない箱（インライン）。文中の一部を囲む

表

タグ読み・由来説明
<table>テーブル表ぜんたい
<thead>table head見出し行のグループ
<tbody>table bodyデータ行のグループ
<tr>table row1行
<th>table header見出しのマス（太字・中央）
<td>table dataデータのマス
colspan="2"—横に2マス分つなげる
rowspan="2"—縦に2マス分つなげる

フォーム

書き方できるもの
<form>入力欄のまとまり
<label for="x">項目名。for と id をそろえると文字を押しても反応する
<input type="text">1行の入力欄
<input type="email">メール用（形式チェック付き）
<input type="number">数字だけの入力欄
<input type="radio">1つだけ選ぶ。同じグループは name をそろえる
<input type="checkbox">複数選べる四角
<input type="range">スライダー
<input type="color">色を選ぶ
<input type="date">日付を選ぶ
<textarea>複数行の入力欄
<select> + <option>プルダウン
<button>押せるボタン
placeholder="…"入力前に薄く出る案内文
required入力必須にする
disabled押せない・入力できない状態にする

よく使う属性

属性説明
class="名前"名札。何個にでも付けられる。CSSで .名前 と指定
id="名前"1ページに1つだけの名前。CSSで #名前、JSで getElementById
style="…"そのタグだけにCSSを直接書く（多用しない）
src="…"読み込むファイルの場所（img, script, video）
href="…"リンク先（a, link）
alt="…"画像の説明文
width / height幅・高さ（px）
data-〇〇="…"自由に付けられる情報。JSから 要素.dataset.〇〇 で読める

特殊文字（そのまま書けない文字）

書き方表示説明
&lt;<小なり。タグと区別するため
&gt;>大なり
&amp;&アンパサンド
&quot;"ダブルクォート
&nbsp;（空白）消えない半角スペース

パソコンとファイルの基本

プログラミングを始めた人が最初に詰まるのは、文法ではなくここ。
半角と全角、拡張子、フォルダの場所。先に知っておくと、無駄に悩む時間がゼロになる。

半角と全角記号の打ち方拡張子 フォルダとパス保存とリロード コピペの罠名前の付け方よく聞く操作

半角と全角 ── 最大の敵

プログラムの記号はすべて半角。全角が1文字でも混ざると動かない。 そして見た目でほとんど区別がつかない。

× 全角（動かない）

（　）　＜　＞　”　’　：　；　，　．

少し幅が広く、文字と文字の間隔があいて見える。

○ 半角（正しい）

( ) < > " ' : ; , .

こちらを使う。

切り替え方

操作結果
半角/全角 キー（Escの下）日本語入力のオン／オフを切り替え
画面右下の表示「あ」＝日本語（危険）／「A」＝半角（安全）
いちばん多い事故 日本語でコメントや文字を打ったあと、オフに戻すのを忘れて記号を打つ。
→ <p>こんにちは＜/p＞ のようになる。色が変わらないタグは全角を疑って。

見分けるコツ

  • VSCodeで色が付かない … タグや文字列が色分けされていなければ、ほぼ全角
  • 波線が出る … 赤や黄色の波線は「おかしいよ」のサイン
  • スペースが妙に広い … 全角スペースが紛れ込んでいる（これも動かない原因になる）
日本語を書いていい場所 タグにはさまれた文章と、コメントの中だけ。
<p>ここは日本語OK</p> /* ここもOK */

拡張子 ── ファイルの種類を決めるもの

ファイル名のうしろに付く .html の部分。パソコンはここを見て種類を判断している。 中身が同じでも、拡張子が違えば別のものとして扱われる。

拡張子中身アイコン／開くもの
.htmlWebページの骨組みブラウザで開く
.css見た目の指定単体では何も表示されない
.js動きのプログラム単体では何も表示されない
.txtただのテキストメモ帳で開く
.png .jpg .webp画像フォト等で開く
.mp3音音楽プレイヤーで開く
いちばん多い事故：二重拡張子 メモ帳で保存すると、勝手に index.html.txt になることがある。
これを防ぐために、拡張子を表示する設定を必ずやっておいて。
メモ帳で保存するときは、ファイルの種類を「すべてのファイル」にしてから保存する。
拡張子は自由に変えられる ファイル名を変えるだけで .txt → .html にできる（中身は変わらない）。
「本当に変更しますか？」と聞かれたら はい。

フォルダとパス ── 「どこにあるか」の書き方

プログラムは ファイルの場所を自分で探してくれない。 「ここにあるよ」と道順を教える必要がある。この道順をパスという。

まずフォルダの形を覚える

index.html から見た道順

書き方意味読み方
style.css同じフォルダの中「となりにある style.css」
img/photo.pngimg の中へ降りる「img フォルダの中の photo.png」
../index.html1つ上のフォルダへ「1つ上に戻って index.html」
../img/a.png上がってから降りる「1つ上の img の中の a.png」
https://…ネット上住所そのもの
覚えるのは2つだけ / は「中に入る」、../ は「1つ戻る」。
迷ったら、エクスプローラーでそのフォルダを開いてみるのがいちばん早い。

「画像が出ない」ときのチェック順

  1. ファイル名のスペルは合っているか（photo と phote）
  2. 拡張子は合っているか（.jpg と .jpeg は別物）
  3. 大文字小文字は合っているか（Photo.png と photo.png）
  4. フォルダの階層は合っているか（img/ を書き忘れていないか）
  5. そもそもその場所にファイルがあるか（エクスプローラーで確認）

VSCodeでは、パスの部分にマウスを乗せて Ctrl を押しながらクリックすると、 正しければそのファイルが開く。開かなければパスが間違っている。これが一番速い確認方法。

保存とリロード ── 反映されない9割の原因

よくある勘違い

「コードを書いたのに、ブラウザが変わらない」

書いただけでは、パソコンの中のファイルはまだ変わっていない。

正しい流れ

書く → Ctrl + S で保存 → ブラウザで F5

この3つでワンセット。

操作意味
Ctrl + S保存。VSCodeのタブの ● が消えれば成功
F5ブラウザを読み込み直す
Ctrl + Shift + R強制読み込み。それでも変わらないときに使う
Ctrl + Z元に戻す（何回でも戻せる）
Ctrl + Y戻しすぎたときのやり直し
キャッシュって何？ ブラウザは、一度読んだファイルを一時的に覚えておく（そのほうが速いので）。 そのせいで、直したのに古いままの表示が出ることがある。 Ctrl + Shift + R は「覚えてるやつは無視して読み直せ」という意味。

コピペの罠

ネットやPDFからコードをコピーすると、見えない余計なものが一緒に付いてくることがある。

起きること直し方
クォートが “ ”（曲がった引用符）になっている 半角の " に打ち直す。PDFやWordからのコピペで頻発
全角スペースが混ざっている その行を打ち直す。VSCodeの設定で全角スペースを表示させることもできる
改行が変な位置に入る Shift + Alt + F で整形
インデントがぐちゃぐちゃ 同じく Shift + Alt + F
おすすめ この教材のコードブロックは、マウスを乗せると出る「コピー」ボタンから取って。 余計なものが付かない。
でも、最初のうちは手で打ったほうがいい コピペだと記号を打つ練習にならないし、記憶にも残らない。 DAY 1〜3 くらいまでは、面倒でも手で打つことをおすすめする。

名前の付け方

○ 安全

index.html

photo_01.png

× 避ける

ホームページ.html（日本語）

Index.HTML（大文字混在）
#1ページ.html（記号）

日本語やスペースは、今は動いても公開したときに壊れることがある。 最初から半角英数字にしておくのが一番ラク。

index.html だけは特別 Webの世界では index.html ＝ そのフォルダの玄関という決まりがある。 公開したとき、この名前のファイルが自動で最初に開かれる。トップページは必ずこの名前に。

よく言われる操作の言い方

言われたことやること
「ターミナルを開いて」VSCodeで Ctrl + `（Shift+@ の左のキー）
「F12を開いて」ブラウザで F12。開発者ツールが出る
「コンソールを見て」F12 を押して、上の Console タブ
「検証して」調べたい所を右クリック →「検証」
「パスを通して」インストール時の「PATH への追加」のこと。VSCodeは初期状態でON
「リロードして」F5
「コメントアウトして」その行を選んで Ctrl + /
「インデントを揃えて」Shift + Alt + F
「エラーを貼って」F12のConsoleの赤い文字を選択してコピー
「ソースを見せて」書いているHTML/CSS/JSのコードそのもの
ここが分かれば、8割の「動かない」は自力で解決できる 文法を覚えるより先に、この資料の内容が身についているほうが、結果的にずっと速く進む。 分からなくなったら、いつでもここに戻ってきて。

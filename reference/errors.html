CSS の症状

症状原因直し方
CSSがまったく効かないlink の書き忘れ・パスミスhead に <link rel="stylesheet" href="style.css">
途中から効かなくなるセミコロンの書き忘れ; が無いと、そこから下がまとめて無効になる
1つの指定だけ効かないセレクタのミスclass は .名前、id は #名前。点とシャープの付け忘れ
指定が上書きされる詳細度の負けF12 で見ると取り消し線が付いている。より細かく指定する
横に並ばないブロック要素は縦に積まれる親に display: flex
中央に寄らないwidth が無いmargin: 0 auto は幅が決まっているときだけ効く
幅がはみ出すpadding が幅に加算されている* { box-sizing: border-box; } を書く
余白が思ったより狭いマージンの相殺上下の margin は大きいほうだけ効く。片方を padding にする
z-index が効かないposition が staticposition: relative などを付ける
スマホで文字が極小viewport の meta が無いhead に viewport の meta を追加
直したのに反映されないキャッシュCtrl + Shift + R

エラーメッセージの読み方

Console の赤い文字には ①種類 ②内容 ③場所（ファイル名:行番号） が必ず書いてある。行番号をクリックすると該当箇所へ飛べる。

メッセージ意味だいたいの原因
Cannot read properties of null存在しないものを触ったid のスペルミス／script が head にある／HTMLに無い
〇〇 is not definedそんな名前は無い変数名・関数名のタイプミス（大文字小文字も別物）
〇〇 is not a function関数じゃないものを呼んだメソッド名のつづり違い（addEventListner など）
Unexpected token文法がおかしいかっこ・クォートの閉じ忘れ、全角文字の混入
Unexpected end of input途中で終わっている} の閉じ忘れ
Assignment to constant variableconst を書き換えたlet にする
Cannot read properties of undefined配列の範囲外など配列は0から数える。a[3] は3個の配列に無い
Maximum call stack size exceeded無限に呼び合っている関数が自分を呼び続けている
Failed to load resource: 404ファイルが見つからないパスかファイル名のミス
Uncaught SyntaxError書き方の間違い行番号の1つ前の行も見ること
英語が分からなくても大丈夫 エラー文をそのままコピーして、AIか検索窓に貼って。 これは「ズル」ではなく、プロが毎日やっていること。
→ AIへの質問文メーカー が、貼る文を作ってくれる。
いちばん最初のエラーだけ見る 10個出ていても、たいてい1個目が原因で残りはその巻き添え。

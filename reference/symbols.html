かっこ

記号読み方どこで使う
( )まるかっこ／パーレン関数。rollDice() Math.floor(x)
{ }なみかっこ／ブレースCSSのまとまり、JSの処理のまとまり、オブジェクト
[ ]かくかっこ／ブラケット配列。[1, 2, 3] likes[0]
< >やまかっこ／不等号HTMLタグ。JSでは大小の比較
かっこは必ずペア 開いたら必ず閉じる。VSCodeでは片方をクリックすると相方が光る。 「Unexpected end of input」というエラーは、たいてい } の閉じ忘れ。

区切り記号

記号読み方意味・使いどころ
;セミコロン1行の終わり。CSSとJSで使う。忘れると次の行まで壊れる
:コロンCSSの「何を：どうする」の区切り。オブジェクトの「名前：値」
,カンマものを並べる。[1, 2, 3]
.ドット／ピリオド「〜の」。state.mood＝stateのmood。CSSではclass
"ダブルクォート文字列を囲む。HTMLの属性の値
'シングルクォート同じく文字列。どちらでもよい
`バッククォートJSの文字列。中で ${ } が使える
/スラッシュ終了タグ、パスの区切り、割り算、コメント
\バックスラッシュ／円マーク特別な文字を打つとき。日本語キーボードでは ￥ と同じキー

その他の記号

記号読み方意味・使いどころ
-ハイフン／マイナスCSSのプロパティ名（font-size）、引き算
_アンダースコア／アンダーバー名前の区切り（my_file）
=イコール代入（入れる）。比較は === で3つ
+プラス足し算。文字列だと連結になる
*アスタリスク／こめじるしかけ算。CSSでは「すべて」
%パーセントCSSでは割合。JSではあまり
#シャープ／ハッシュCSSのid、色コード（#ff0000）
$ドルJSの ${ 変数 } で使う
&アンパサンド&& で「かつ」
|パイプ／縦棒|| で「または」
!エクスクラメーション／びっくり「〜でない」。!== は「等しくない」
?クエスチョン／はてな三項演算子、URLの区切り
@アットマークCSSの @media @keyframes
>大なりCSSでは「直接の子」、Emmetでは「中に入れる」
//スラッシュ2つJSのコメント（その行は無視される）
/* */スラッシュアスタリスクCSSのコメント

よく出る英単語

プログラムの名前は英語。単語の意味が分かるだけで、初めて見るコードも半分読める。

単語読み意味

setセット設定する・入れる
addアド足す
removeリムーブ取り除く
createクリエイト作る
appendアペンド末尾にくっつける
toggleトグル切り替える
selectセレクト選ぶ

キーできること

Ctrl + Z元に戻す。壊したらこれ（Ctrl + Y でやり直し）
Shift + Alt + F自動で整形。インデントがぐちゃぐちゃになったら
この3つだけで戦える あとは使いながら少しずつで大丈夫。全部覚えようとしないこと。

Emmet（入力補助）

HTMLファイルで省略形を打って Tab を押すと、タグに展開される。慣れると入力量が半分以下になる。

打つもの出てくるもの
! → TabHTMLの骨組み一式（DOCTYPE から body まで）
div → Tab<div></div>
.box → Tab<div class="box"></div>
#head → Tab<div id="head"></div>
p.lead → Tab<p class="lead"></p>
ul>li*3 → Tabul の中に li が3つ
.card*4 → Tabclass="card" の div が4つ
table>tr*3>td*2 → Tab3行2列の表
a[href="#"] → Tab<a href="#"></a>
h2{見出し} → Tab<h2>見出し</h2>
lorem → Tabダミーの文章（レイアウト確認用）
記号の意味 .＝class／#＝id／>＝中に入れる／*＝繰り返す／ { }＝中身の文字／[ ]＝属性

入れておくと良い拡張機能

名前何ができるか
Japanese Language Packメニューが日本語になる
Live Server保存した瞬間にブラウザが自動更新。右クリック →「Open with Live Server」
Auto Rename Tag開始タグを直すと終了タグも一緒に変わる
indent-rainbowインデントに色が付いて、入れ子が見やすくなる
Color HighlightCSSの色コードの横に実際の色が表示される
入れすぎ注意 「便利そう」で10個入れると重くなる。困ってから足すのが正解。 まずは日本語化と Live Server の2つで十分。

用語辞典

Web制作でよく出てくる言葉を、できるだけ短い日本語で説明している。授業中に「それ何？」と思ったらここへ。

基本ファイルまわりHTML用語 CSS用語JavaScript用語道具 Webのしくみ現場のことば

基本

用語意味
HTMLページの骨組みを作る言語。「ここは見出し」「ここは画像」と意味を決める
CSSページの見た目を決める言語。色・大きさ・並び方
JavaScript（JS）ページに動きを付ける言語。ブラウザが理解できる唯一のプログラミング言語
ブラウザHTMLを読んで画面に描くアプリ。Chrome, Edge, Safari, Firefox など
フロントエンドユーザーの目に見える側。HTML/CSS/JS の担当範囲
バックエンドサーバー側の見えない処理。Python や PHP などが使われる
レスポンシブ画面の広さに合わせてレイアウトが変わること
デバッグバグ（不具合）を見つけて直す作業

ファイルまわり

用語意味
拡張子ファイル名の最後の .html .css .js の部分。中身の種類を表す
パスファイルまでの道順。img/photo.png など
相対パス今いる場所からの道順。../ で1つ上へ
絶対パス先頭からの完全な道順。https://… など
index.htmlそのフォルダの玄関。公開時に自動で最初に開かれる
文字コード文字を数値で表す方式。Webでは UTF-8 を使う
文字化け文字コードの指定ミスで文字が壊れて表示されること
ディレクトリフォルダのこと（プログラミングではこう呼ぶことが多い）

HTML用語

用語意味
タグ<p> のような記号。開始タグと終了タグがある
要素（エレメント）開始タグ＋中身＋終了タグの1セット
属性タグに付ける追加情報。src="…" class="…" など
空要素中身を持たず終了タグが無いタグ。<img> <br>
入れ子（ネスト）タグの中にタグを入れること
ブロック要素横幅いっぱいを取り、縦に積まれる。div p h1
インライン要素中身のぶんだけの幅で、横に並ぶ。span a strong
セマンティック「意味を持つ」。header main など意味のあるタグを使うこと
フォーム入力欄のまとまり
alt属性画像の説明文。読み上げソフトや画像が出ないときに使われる

CSS用語

用語意味
セレクタ「どこを」指定する部分。.box #head p
プロパティ「何を」変えるか。color margin など
値「どうする」か。red 20px など
宣言プロパティ: 値; のセット
ボックスモデルすべての要素が持つ4層の構造（content / padding / border / margin）
padding枠線の内側の余白
margin枠線の外側の余白
マージンの相殺上下に並んだ margin が足し算されず、大きいほうだけ効く現象
Flexbox要素を一列に並べる仕組み
Grid要素を格子状に並べる仕組み
疑似クラス:hover のような「状態」を指定するもの
疑似要素::before のような「無い要素を足す」もの
メディアクエリ@media。画面幅で CSS を書き分ける仕組み
CSS変数--main: red; で作り var(--main) で使う。色の一括管理に
詳細度同じ場所に複数のCSSが当たったときの強さ。細かく指定したほうが勝つ

JavaScript用語

用語意味
変数値に名前をつけた箱。const let
型データの種類。数値・文字列・真偽値・配列・オブジェクト
配列順番に並んだ箱。[1, 2, 3]
オブジェクト名前つきの箱。{ name: "ユウ" }
関数処理に名前をつけたもの
引数関数に渡す値
戻り値関数が返す値（return）
メソッド何かにくっついた関数。配列.push() の push など
イベントクリックや入力などの「起きたこと」
イベントリスナー「〜されたら実行する」という予約
DOMブラウザが読み込んだHTMLを、JSから触れる形にしたもの
状態（state）今の状況を表すデータ。これを直して画面を作り直すのが基本
null「何も無い」。要素が見つからないときに返る
undefined「まだ入っていない」
コールバック他の関数に渡して、あとで呼んでもらう関数
localStorageブラウザにデータを保存する仕組み。そのブラウザの中だけ
JSONデータを文字列で表す形式。保存や通信に使う

道具

用語意味
VSCodeMicrosoft の無料エディタ。この講座で使う
エディタコードを書くためのソフト
拡張機能VSCode に後から足す機能
EmmetVSCode の入力補助。! + Tab で骨組みが出る
Live Server保存すると自動でブラウザが更新される拡張機能
開発者ツール（DevTools）F12 で開くブラウザの検査ツール
コンソール開発者ツールの中で、ログとエラーが出る場所
Git / GitHubコードの変更履歴を管理する仕組みと、その置き場所サービス
GitHub PagesGitHub に置いたファイルをそのままWebサイトとして公開できる機能
FirebaseGoogle の、サーバーを用意せずにデータ保存やログインが使えるサービス

Webのしくみ

用語意味
URLページの住所。https://example.com/page.html
ドメインURLの example.com の部分
サーバーファイルを置いておき、ブラウザからの求めに応えてファイルを返すコンピュータ
クライアントお願いする側。つまりブラウザ
HTTP / HTTPSやりとりの決まりごと。HTTPS は暗号化されている
キャッシュ一度読んだファイルの一時保存。更新が反映されない原因になる（Ctrl+Shift+R で無視）
404「ファイルが見つかりません」というエラー番号
デプロイ作ったものを公開すること
ホスティングファイルを置かせてくれるサービス

現場のことば

用語意味
コメントアウトコードを一時的に無効にすること
リファクタリング動きを変えずにコードを整理すること
ハードコーディング値を直接書き込むこと。後で変えにくくなる
ワイヤーフレーム画面の配置だけを描いたラフ図
モックアップ見た目だけ作った試作
アクティビティ図処理の流れを四角と矢印で描いた図
仕様「こう動くべき」という決めごと
UIUser Interface。人が触る部分（ボタンや画面）
UXUser Experience。使ったときの体験・使い心地
アクセシビリティ誰でも（目が見えない人も）使えるようにする配慮
MVP最小限の動くもの。まずこれを作って、あとから足す

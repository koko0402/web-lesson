推しの紹介サイトを作る

HTML と CSS だけで、1ページのファンサイトを作る。JavaScript は使わない。
習ったことを全部ここで使う。だいたい2〜3時間（授業1回＋宿題）を見ている。

完成イメージ

これは見本。同じものを作る必要はない。構成だけ真似して、中身は自分の推しで埋めて。

パソコンで見たところ
スマホで見たところ。同じHTML
スターターを開く（ここから作る） 完成見本を開く
見本を先に読まないこと 答えを見てから書くと、「読めた」だけで「書ける」ようにはならない。 まず自分で書いて、詰まってから見本を開いて。詰まる時間そのものが練習。

ねらい

この課題が終わると、次のことが自分でできるようになる。

  • 白紙から、ページの構成を自分で決められる
  • 「こういう見た目にしたい」を CSS のプロパティに翻訳できる
  • ヘッダー・カード・ギャラリーという、どのサイトにもある部品を作れる
  • スマホで見ても崩れないページにできる
なぜ「推し」なのか 題材が自分ごとだと、書きたいことが先にある状態で作れる。 「サンプルテキスト」を並べる練習より、ずっと手が動く。 推しがいなければ、好きな食べもの・行った場所・飼っている動物でも構わない。

必須要件

これが入っていれば合格。スターターの骨組みを使えば、構成は自動的に満たせる。

HTML

項目内容
見出しh1 はページに1つだけ（推しの名前）。h2 は各セクションに1つずつ
文章p で2段落以上。強調したい語は strong で囲む
画像img を4枚以上。alt に「何が写っているか」を必ず書く
リンクa でページ内移動（#id）を1つ以上
表table で基本データを5行以上
区切りsection でまとまりを分け、id を付ける

CSS

項目内容
置き場所別ファイル（style.css）に書く。HTMLの中に書かない
色基本は3色まで。:root の変数にまとめる
横並びdisplay:flex を2か所以上（ヘッダー・カード・ギャラリー）
中央寄せmax-width ＋ margin:0 auto で本文の幅を決める
画像object-fit:cover で、大きさの違う画像をそろえる
動き:hover を1か所以上。transition も添える
スマホ幅400pxまで狭めても、横スクロールが出ない

進め方

いきなり書きはじめないで。①と②で全体の8割が決まる。

  1. 紙に描く（15分）
    どのセクションを、どの順で置くか。紙に長方形を並べるだけで十分。 ここで「何を伝えたいか」が決まっていないと、あとで必ず手が止まる。
  2. 材料をそろえる（20分）
    画像4枚を img フォルダに入れ、紹介文を先にメモ帳で書ききってしまう。 文章を考えながらHTMLを書くと、どちらも中途半端になる。
  3. HTMLだけ仕上げる（40分）
    CSSは一切さわらず、中身だけ全部入れる。この時点ではまっ白でダサくて正解。 見た目が気になっても、ここは我慢して。
  4. CSSで飾る（60分）
    スターターの ★A から順に埋めていく。 迷ったら CSS見本帳 から値を選んでコピーして。
  5. 狭くして確かめる（10分）
    ブラウザの窓をスマホくらいの幅まで狭めてむ。 崩れたら flex-wrap: wrap; が抜けていないか確認して。
③と④を混ぜないこと 初心者がいちばん時間を溶かすのが、中身を書きながら色を変えるやり方。 HTMLを全部終わらせてからCSSに移ると、同じ内容でも半分の時間で終わる。

★の一覧（スターターの穴うめ）

starter/index.html と starter/style.css に、 ★ 付きのコメントが入っている。全部で HTML 13か所・CSS 14か所。

style.css のほう（ここが本番）

HTML の ★1〜★13 は、 タイトル・名前・紹介文など中身を入れるだけ。順番に埋めて。

画像の注意（ここは必ず読む）

作ったものは、そのままネットに上げない 公式サイトや SNS から保存した画像には、撮った人・描いた人の権利がある。 自分のパソコンの中で練習するぶんには問題ないが、 そのまま公開すると権利の侵害になる。
やりたいことどうするか
手元で練習する拾ってきた画像でも大丈夫。公開しなければよい
人に見せたいUSBやファイル送信でファイルごと渡す。これは公開ではない
ネットに公開したい自分で撮った／描いた画像、公式が配布している素材、 フリー素材サイトのものに差し替えてから

あわせて、フッターに 「これはファンページ。公式とは関係ありません」 と書いておく。 スターターの ★13 がその場所。ファンサイトの作法として、これは書く側の常識になっている。

権利の話は面倒に聞こえるが、逆に言えば「自分で撮った写真なら何をしてもいい」ということでもある。 推しがアイドルでもキャラクターでもない場合 ── たとえば飼っている猫や、好きなラーメン屋の一杯なら ── 自分で撮った写真がそのまま使える。公開まで見すえるなら、そちらのほうが自由に作れる。

できたらやること

必須要件が終わって、まだ時間があるとき用。やらなくても構わない。

  • カードを3枚から5枚に増やす（article をコピーするだけ）
  • ギャラリーの画像に :hover で少し拡大する動きをつける
  • 2ページ目（gallery.html など）を作って、ヘッダーのメニューからつなぐ
  • Google Fonts でWebフォントを読み込んで、見出しの書体を変える
  • background-image で、主役のところに背景写真を敷く

提出前のチェック

  • ブラウザのタブに、推しの名前が出ている（title）
  • 画像が4枚とも表示されている（×印になっていない）
  • すべての img に alt が書いてある
  • メニューをクリックすると、そのセクションに飛ぶ
  • 窓を狭めても横スクロールが出ない
  • マウスを乗せると変化する場所が、1つ以上ある
  • フッターにファンページである旨が書いてある
  • CSSが style.css に分かれている
提出のしかた フォルダごと ZIP にして渡す。index.html・style.css・img フォルダが 同じ階層に入っていることを確認して。 画像だけ別の場所に置いていると、渡した先で表示されない。

教える側へのメモ

  • ①の「紙に描く」を飛ばさせないこと。 ここを省くと、④で必ず迷子になる
  • 画像は初回までに用意させておくと、授業中に探す時間が消える
  • ③が終わった時点で一度見せてもらうと、HTMLの構造ミスを早く拾える
  • 色選びで止まる子には、推しの画像から3色スポイトするよう言うと早い
  • 「見本と同じにならない」と気にする子には、同じにする課題ではないと伝えて
  • 時間が足りないときは、ギャラリーと表を削ってヘッダー＋主役＋カード3枚だけでも成立する

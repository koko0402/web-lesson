ページの地図を作る

場所に名前をつけるタグ

タグその場所の意味
<header>ページの上部・題名やロゴ
<nav>他のページへのリンク集
<main>そのページの主役。1ページに1つ
<section>意味のまとまり。見出しとセット
<article>それ単体で成立する記事
<aside>おまけ・補足・サイドバー
<footer>ページの下部・著作表示
見た目は1ミリも変わらない これらはブラウザや読み上げソフトに構造を伝えるためのタグ。 「後から自分が読んで分かる」のも大きな利点。
意味のない箱

div と span ── ただの入れ物

意味を持たないタグ。「ここをまとめてCSSで飾りたい」というときの目印として使う。

  • div ＝ ブロックの入れ物
  • span ＝ インラインの入れ物

class 属性 ＝ 名札

タグに付ける名前。同じ名前を何個でも付けられる。 次回、この名札を目印にしてCSSで色を付ける。

半角スペースで区切ると複数の名札を付けられる。

div を使いすぎない 意味のあるタグ（section・header など）が使える場所ではそちらを使う。 全部 div のページは、後から読むと何がどこか分からない。

パスの復習

同じ階層ならファイル名だけでつながる。 href="spec.html"

同じものを何度も書くのがつらい？ その通り。今は手でコピーするが、この「共通部分の使い回し」を 楽にする仕組みが世の中にはたくさんある。つらさを覚えておくと、後で有り難みが分かる。

大事な注意

このフォーム、まだ送れない

送信ボタンを押しても、どこにも届かない。 受け取る側の仕組みが無いから。

実習

手順

  1. day2 フォルダを作り、DAY 1 の index.html と img をコピー

DAY 2 のつまずき

① リンクを押すと真っ白

「ファイルが見つかりません」と出る。
→ href のファイル名ミス。拡張子 .html まで正確に。 spec.html と Spec.html は別物。

② 表がぐちゃぐちゃ

マスの数が合わない。
→ <tr> の閉じ忘れ、または行ごとの <td> の数が違う。 全部の行で同じ数にそろえる。

③ 画像が出なくなった

day1 では出ていたのに。
→ img フォルダをコピーし忘れ。 HTMLだけ移動しても画像は付いてこない。

④ ラジオボタンが複数選べる

1つだけ選ばせたいのに。
→ 同じグループの radio には同じ name を付ける。 name="yoken" でそろえる。

今日から使えるデバッグ ブラウザで F12 → 上のタブの Elements。自分の書いたHTMLがそのまま出ている。 赤く出ている部分があれば、そこが壊れている。

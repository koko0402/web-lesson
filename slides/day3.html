「どこを」の指定方法

セレクタ ── 3つ覚えれば足りる

① タグ名

そのタグ全部が対象。 ページ中の <p> がすべて灰色になる。

全体の土台を作るときに使う。

② class（名札）

HTML側で class="box" と付けた要素だけ。頭に半角ピリオド。

ふだん使うのは9割これ。

③ id（1つだけの名前）

HTML側で id="header"。頭に半角シャープ。

1ページに1個だけ。JS で使うことが多い。

組み合わせも書ける .box p ＝ box の中にある p だけ（半角スペースで「〜の中の」）
h1, h2 ＝ h1 と h2 の両方（カンマで「〜と〜」）
迷ったら class タグ名だと範囲が広すぎ、id だと1個にしか使えない。 class は何個にでも付けられるので一番扱いやすい。

今日いちばん大事

すべての要素は「四角い箱」

margin（外の余白）
border（枠線）
padding（内の余白）
content（中身）
名前場所使いどころ
contentいちばん内側文字や画像そのもの
padding中身と枠線の間箱の中を広げる
border枠線囲む・区切る
margin枠線の外側箱どうしを離す
使い分けのコツ 中を広げたい → padding／まわりを空けたい → margin。 背景色を付けると違いが一発で分かる。
これを最初に書いておくと楽 * { box-sizing: border-box; }
padding や border を足しても全体の幅が変わらなくなり、計算が簡単になる。
プロパティ ③

余白の書き方は4通り

時計回りで覚える 上 → 右 → 下 → 左。
2つのときは「上下・左右」、3つのときは「上・左右・下」。
中央に置く定番 margin: 0 auto;
左右の余白を自動で均等にする＝中央寄せ。 幅（width）が決まっているときだけ効く。
margin の相殺 上下に並んだ箱の margin は足し算されず、大きいほうだけが効く。 「余白が思ったより狭い」の原因はだいたいこれ。

実習

手順

  1. day3 フォルダを作り、DAY 2 のファイルをコピー
  2. 同じ場所に style.css を新規作成
  3. HTMLの head に <link rel="stylesheet" href="style.css"> を追加
  4. まず body に背景色を付けて、効いているか確認
  5. 効いたら、上から順に書き足していく
いきなり全部書かない 1つ書く → 保存 → F5 → 変わったか見る。この往復を細かく。 まとめて書くと、どれが効いていないのか分からなくなる。

「CSSが効かない」ときの確認順

  1. link は書いてある？ head の中に <link rel="stylesheet" href="style.css">。ファイル名のスペルも確認
  2. 保存した？ タブに ● が付いていたら未保存。Ctrl + S
  3. セミコロンを忘れていない？ ; が無いと、その行から下がまとめて無効になる
  4. セレクタは合っている？ class は .box、id は #box。ピリオドやシャープの付け忘れが多い
  5. キャッシュ？ Ctrl + Shift + R で強制読み込み
優先順位（詳しさ勝負） 同じ場所に違う指定が当たったときは、より細かく指定したほうが勝ち。
タグ名 < class < id < style属性
F12 が最強の味方 要素を右クリック →「検証」。当たっているCSSが右側に全部出る。 取り消し線が付いていたら、それは負けている指定。

ブロックで組む

ブロックを積むと、それがそのまま流れ図（アクティビティ図）になり、 同時にプログラムにもなる。
打ち間違いが起きないので、「上から順に実行される」だけに集中できる。

これは何のためのページ？ いきなりコードを書くと、やりたいことより先に「打ち間違い」と戦うことになる。 ここでは選ぶだけで組めるので、考え方だけを先に体に入れられる。 右の「できたプログラム」は本物。そのままコピーして使える。

ブロックと、プログラムの対応

左のブロックが、右の書き方にそのまま変わる。ここを見比べるのが、いちばんの近道。

ブロックプログラム名前
〇〇の文字を△△にするmidashi.textContent = "△△";代入
〇〇の色を△△にするmaru.style.background = "△△";スタイルの変更
かずを1ふやすkazu = kazu + 1;変数
もし〜なら／でなければif (kazu > 3) { … } else { … }条件分岐
〇回くりかえすfor (let i = 0; i < 3; i++) { … }繰り返し
流れ図（アクティビティ図）の読み方 ●がはじめ、◉がおわり。角丸の四角がやること、ひし形が分かれ道。 上から下へ矢印をたどるだけ。プログラムも同じで、上から順に実行される。
慣れたら、こっちへ ブロックで作れるものが分かってきたら、 DAY 5（JavaScript ①）へ。 ここで出てきた textContent や if を、自分の手で書いていく。

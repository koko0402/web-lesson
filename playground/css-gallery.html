CSS見本帳

「これを選ぶと、こうなる」を実物で並べた。
コードの行をクリックするとコピーできる。そのまま自分の style.css に貼って。

使い方のコツ 暗記しようとしないで。作りたい見た目から逆に探すための本。 「もっと丸くしたい」と思ったら ③ を見る、「横に並べたい」と思ったら ⑤ を見る、という使い方をする。
① 文字 ② 色 ③ 枠・角・影 ④ 余白とサイズ ⑤ 横に並べる ⑥ 位置を決める ⑦ 画像 ⑧ そのほか

width ── 横幅の指定のしかた

width: auto初期値。横いっぱいに広がる
実戦ではこの組み合わせが多い width:100%; max-width:800px; margin:0 auto;
「広い画面では800pxで止めて中央に、狭い画面では画面いっぱいに」という意味。 スマホでもPCでも崩れないので、ページ全体の外枠によく使う。

margin: 0 auto ── 中央に置く

margin なし
margin: 0左に寄ったまま
margin: 0 auto
margin: 0 auto左右の余白を等分＝中央に来る
margin: 0 auto が効かないとき width を指定していないのが原因。幅が「横いっぱい」のままだと、 中央に寄せる余白が残らない。まず width か max-width を決めて。

box-sizing ── 幅の数え方

width:180px
でも実際は214px
box-sizing: content-box初期値。padding と border が外側に足される
width:180px
ぴったり180px
box-sizing: border-box枠込みで180px。計算が楽
最初に1回だけ書いておくおまじない * { box-sizing: border-box; } を style.css のいちばん上に書いておくと、 全部の要素が右側の数え方になる。レイアウトがずれる事故が激減するので、 毎回書いてしまって構わない。

⑦ 画像

画像は「枠のサイズ」と「中身の入れ方」を別々に決める。object-fit を知らないと画像がつぶれる。

object-fit ── 枠への入れ方

object-fit: fill初期値。つぶれる／伸びる
object-fit: contain全体が入る。すき間ができる
object-fit: cover枠を埋める。はみ出しは切る。ふつうこれ
object-fit: none原寸のまま。中央だけ見える

まるく切り抜く／サイズを決める

border-radius: 50%アイコンの定番
width: 100%親の幅に合わせる
max-width: 100%; height: auto縦横比を保ったまま縮む。必ず書く
画像が出ないときに見るところ ① ファイル名のつづりと大文字小文字が合っているか　② img/ フォルダの中にあるか　③ .jpg と .jpeg を間違えていないか。 くわしくは エラー辞典。

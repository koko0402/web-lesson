① 使い方 ── どのフォントも、やることは3つだけ

1. head に1行貼る

これが「ダウンロードするためのコマンド」。 書いた瞬間に、見に来た人のブラウザがフォントを取りに行く。

<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Noto+Sans+JP&display=swap">

2. CSS で指定する

body { font-family: "Noto Sans JP", sans-serif; }

3. 終わり

2つ目の sans-serif は保険。 1つ目が読めなかったときに、これが使われる。必ず付ける。

「入っている」と「貼れば使える」は別 ②はその端末に最初から入っているフォント。貼る必要はないが、 持っていない人には別のフォントで表示される。
③④は貼れば誰の画面でも同じに出る。迷ったらこっち。
日本語フォントは重い ひらがな・カタカナ・漢字で数千文字あるので、英数字だけのフォントの何十倍も大きい。 1つのサイトで使うのは1〜2種類までにしておく。
display=swap は付けておく フォントが届くまで、とりあえず手持ちのフォントで表示してくれる。 付けないと、届くまで文字が真っ白になることがある。

④ 貼れば使えるフォント（英数字）

英数字だけのフォントは軽いので、気軽に使える。 日本語は出ないので、日本語フォントと並べて書く（先に書いたほうが優先される）。

font-family: "Montserrat", "Noto Sans JP", sans-serif; /* 英数字は Montserrat、日本語は Noto Sans JP になる */

⑤ ファイルを落として使う

Google Fonts に無いフォントは、配布サイトからファイル（.woff2 / .otf / .ttf）を落として、 自分のサイトに置いて使う。手順は2つ。

1. フォルダに置く

わたしのサイト/ ├ index.html ├ style.css └ fonts/ └ MyFont.woff2 ← ここに置く

2. CSS の先頭で読み込む

@font-face { font-family: "マイフォント"; /* 好きな名前でいい */ src: url("fonts/MyFont.woff2") format("woff2"); font-display: swap; } h1 { font-family: "マイフォント", sans-serif; }
いちばん大事：使っていい条件を見る 無料でも「個人利用だけ」「商用は連絡が必要」「再配布はだめ」など、 条件はフォントごとに違う。落とす前に、配布ページの 利用規約・ライセンスを必ず読むこと。
.woff2 に変換すると軽くなる .otf や .ttf のままでも動くが、 Web用の .woff2 にすると半分以下になる。 「woff2 変換」で検索すると変換サイトが出てくる。
パソコンに入れる（インストール）とは別 ファイルをダブルクリックして「インストール」すると、 Word などでは使えるようになるが、サイトを見に来た人には出ない。 サイトで使うには、上の @font-face が必要。

⑦ 選び方のコツ

2種類まで 見出しに1つ、本文に1つ。これ以上増やすと、とたんに素人っぽくなる。 変化を付けたいときは、フォントではなく太さと大きさで付ける。
本文はふつうのフォントで かわいいフォントや細すぎるフォントは、長い文章だと読めない。 本文はゴシックか明朝。遊ぶのは見出しだけ。
太さは、使うぶんだけ読み込む wght@400;700 のように書くと、その2つだけ落ちてくる。 全部入れると重くなる。

写真のページ

スマホで撮った写真は、そのままだと1枚 4〜8MBある。
10枚貼ったら50MB。スマホの回線だと、開くまで1分くらいかかる。ここで軽くしてから使う。

① 軽くする ② 形式の使い分け ③ 大きさの目安 ④ HTMLの書き方 ⑤ alt の書き方 ⑥ 使っていい写真

① 軽くする

どこにも送られない この変換は全部このブラウザの中だけでやっている。 写真がインターネットに出ることはないし、俺も見られない。 ネットを切ったままでも動く。

画質は 80 くらいで、見た目はほとんど変わらないのに半分以下になる。 迷ったら触らなくていい。

② 形式の使い分け

拡張子ごとに得意なことが違う。写真は webp、図は svg、と覚えておけばだいたい合っている。

拡張子得意なもの 透明大きさひとこと
.webp写真・イラスト どちらも できる軽い いま使うならこれ。jpg の半分くらいになる。今のブラウザなら全部見られる
.jpg写真 できないふつう 昔からある形式。とにかく確実。カメラの写真はだいたいこれ
.png図・スクショ・ロゴ できる重い 写真を png にするととても重くなる。透明が要るときだけ
.svgアイコン・ロゴ・図形 できるすごく軽い 拡大してもぜったいにボケない。中身は文字なので直接書き換えられる
.gif短いパラパラ動画 △重い 色が256色しか出ない。今は動画か webp のほうがいい
.avif写真 できる最強に軽い webp よりさらに軽い。まだ対応していない環境もあるので、今は webp で十分
.heic（iPhoneの写真） —— Webでは使えない。iPhoneから送るときは「互換性優先」にするか、ここで変換する

③ 大きさの目安

「よこ幅 何px にすればいいか」は、画面のどこに置くかで決まる。 置く場所より大きい写真を用意しても、ただ重くなるだけで何も良くならない。

どこに置くよこ幅 重さの目安ひとこと
いちばん上の大きい写真1600px〜300KB ここだけは大きくていい。ただし1枚まで
記事の中の写真1200px〜200KB 迷ったらこれ。だいたい足りる
カード・一覧のタイル800px〜100KB 小さく並ぶので、これで十分きれいに見える
プロフィールのアイコン400px〜50KB 丸く切り抜かれることが多いので正方形で
ロゴ・アイコンsvg〜10KB 大きさの概念がない。どこまで拡大してもきれい
ページ全体で 1〜2MB まで 写真も CSS も JS も全部足した合計。これを超えると、スマホでは目に見えて遅くなる。 写真1枚が 1MB を超えていたら、それはまず大きすぎる。

④ HTMLの書き方

これを全部書く

<img src="img/neko.webp" alt="窓辺で寝ている茶色の猫" width="1200" height="800" loading="lazy">
書くものなぜ書くか
srcどのファイルか。ここを間違えると出ない
alt見えない人・出なかったときのための説明（⑤へ）
width
height		 写真が届く前に場所を空けておける。書かないと、読み込んだ瞬間に下の文がガクッとずれる
loadinglazy と書くと、画面に入るまで読まない。下のほうの写真に効く
出ないときは、だいたいパス img/neko.webp と書いたら、HTMLと同じ場所にある img フォルダの中を見に行く。 大文字小文字も区別される（Neko.webp は別物）。
ファイル名は半角の英数字で ✕ IMG_2831 のコピー.JPG／猫の写真.jpg
○ neko.webp／cat-window.webp
日本語やスペースは、環境によって出たり出なかったりする。
はみ出さないようにする CSS にこの2行を入れておくと、どんな大きさの写真でも枠に収まる。
img { max-width: 100%; height: auto; }

⑤ alt の書き方

その写真が見えない人に、電話で説明するつもりで書く。 目が見えない人が使う読み上げソフトは、ここを読む。写真が出なかったときも、ここが出る。

こう書くなぜ
alt="画像"／alt="IMG_2831" 何も伝わらない。書いてないのと同じ
alt="猫の写真" 「写真」は言わなくていい。どんな猫かが知りたい
alt="窓辺で丸くなって寝ている茶トラの猫" 見えなくても、頭の中に絵が浮かぶ
alt="" 飾りの画像はこれが正解。空にすると読み上げが飛ばしてくれる。 属性ごと消すのはダメ（ファイル名を読み上げてしまう）
alt="もくじに戻る" リンクになっている画像は、見た目ではなく行き先を書く

⑥ 使っていい写真

ネットで拾った写真は使えない 検索して出てきた写真には、撮った人の権利がある。 練習でも、公開するなら使わない。 「自分で撮った」「自分で描いた」「フリー素材」の3つだけにしておけば、まず問題にならない。
どこから公開してOK気をつけること
自分で撮った・描いたOK いちばん安全。人が写っているなら、その人に確認する
フリー素材サイトOK サイトごとに条件が違う。「クレジット表記が要るか」だけは見る
検索で出てきた画像ダメ ほぼ全部、誰かのもの
推し・芸能人・アニメの画像ダメ 肖像権と著作権。推しの紹介サイトを作るなら、写真は自分で描くか、文字だけで作る
AIで作った画像△ 使ったサービスの規約による。学習元の問題もあるので、公開するなら調べてから

よく使われるフリー素材サイト

推しの紹介サイトを作るときは 課題ページにも書いたが、 公式の写真は貼らない。自分で描いたイラスト、自分で撮ったグッズの写真、 文字と色だけのデザイン——このどれかで作る。 フッターに「ファンが作ったページで、公式とは関係ない」と書いておくこと。

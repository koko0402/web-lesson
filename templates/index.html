スターターファイル

毎回ゼロから書くのは大変なので、コピーして使う雛形を3種類用意した。
コメントを読みながら、中身を自分のものに書き換えていって。

使い方
  1. 使いたいフォルダをまるごとコピーする
  2. デスクトップの web の中に貼り付けて、フォルダ名を好きな名前にする
    （半角英数字で。例：omikuji）
  3. VSCode で ファイル → フォルダーを開く
  4. index.html を書き換えていく
ただし、最初のうちは自分で書いたほうがいい DAY 1〜3 くらいまでは、面倒でも ! + Tab から手で書くことをおすすめする。 雛形が役に立つのは、作りたいものができてから。

01HTMLだけ

いちばん小さい形。DAY 1〜2 で使う。

01-html-only/
└─ index.html

→ 開いて見る

02HTML ＋ CSS

ヘッダー・本文・フッターと、色をまとめた CSS 付き。DAY 3〜4 で使う。 CSS変数・max-width での中央寄せ・レスポンシブが最初から入っている。

02-html-css/
├─ index.html
├─ style.css
└─ img/sample.webp

→ 開いて見る

03HTML ＋ CSS ＋ JavaScript

02 に、ボタンで文字が変わると配列からリストを作るの最小セットを足したもの。 DAY 5 以降、自分のアプリを作るときの出発点。

03-html-css-js/
├─ index.html
├─ style.css
├─ script.js
└─ img/sample.webp

→ 開いて見る

script.js の下のほうに、よく使う書き方が コメントアウトした状態でまとめてある（乱数・入力の取得・保存など）。 使いたいものの // を外して使って。

img フォルダについて 画像は img/ にまとめる決まりにしてある。サンプル画像が1枚入っているので、 自分の画像に差し替えて <img src="img/自分のファイル名"> と書けば表示される。
